# Class-Track
Class Track is a simple yet detailed app for Android to track your college classes and manage your schedule.

## Class Track contains all the features you need to manage your schedule:
- Set daily times and locations for each class
- Add multiple sections to a course (for example, add lecture and discussion sections to the same course)
- Track your attendance daily, and get notifications half an hour before classes
- Track your GPA, credits earned, and add gen-ed attributes to class to track your gen-ed progress
- Create PDFs of your schedule in a weekly view or a list view
- Create backup files you can import to use on other devices or if you lose your data

## Class Track is extremely customizable:
- Class Track has light and dark modes
- Class Track has two UI styles: an expressive style and a frosted glassy style
- Customize how late classes are calculated for your attendance

### Best of all, Class Track is completely free. No ads, no microtransactions.
